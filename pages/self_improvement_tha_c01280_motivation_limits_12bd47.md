## Introduction

Wanting a result matters, but wanting it strongly is not the same as reliably doing the behaviour that produces it. Research repeatedly finds an **intention–behaviour gap**: people can form sincere intentions to [exercise]({{ 'exercise/' | relative_url }}), study, eat differently or follow another self-improvement goal without consistently acting on them. In experimental evidence, even fairly large increases in intention have produced much smaller changes in behaviour.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/16536643/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Does changing behavioral intentions engender behavior change? A meta-analysis of the experimental evidence - PubMed...</span></span></span>



<figure class="article-media-figure article-media-figure-overview"><img src="{{ "/assets/images/self_improvement_tha_c01280_motivation_limits_12bd47-overview.webp" | relative_url }}" alt="Overview image for Motivation Limits" width="1536" height="1024" loading="lazy" decoding="async" fetchpriority="low"><figcaption class="article-media-caption"><span class="article-media-caption-label">Illustrative overview</span></figcaption></figure>

This does not make motivation irrelevant. Better-quality, more autonomous motivation is associated with greater persistence, and motivation can be especially important when a behaviour is new. The limitation is that motivation is a changing internal state, while long-term improvement requires action on ordinary days as well as enthusiastic ones. Effective behaviour change therefore uses motivation to choose and begin a direction, then builds ways of acting that require less motivation each time.

## Intention is not execution

A useful distinction in self-improvement is between **deciding to act** and **successfully initiating action when the opportunity arrives**. An intention such as “I am going to exercise three times this week” settles the first problem. It does not automatically solve [remembering]({{ 'remembering/' | relative_url }}), choosing the right moment, stopping another activity, tolerating inconvenience or beginning when the anticipated reward feels distant.

The size of this gap is visible in experimental research. Webb and Sheeran reviewed 47 tests in which an intervention successfully changed people's behavioural intentions and then measured what they actually did. The average change in intention was medium-to-large, with an effect size of 0.66, but the corresponding behavioural change was only 0.36. In other words, making people want or intend something more strongly helped, but much of the additional intention did not become action.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/16536643/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Does changing behavioral intentions engender behavior change? A meta-analysis of the experimental evidence - PubMed...</span></span></span>

Studies following people in daily life make the problem more concrete. In one ecological momentary assessment study, adults repeatedly reported short-term intentions to be physically active and wore accelerometers afterwards. Participants performed at least ten minutes of moderate-to-vigorous activity after only 16% of prompts at which they had reported an intention to exercise. The exact figure should not be generalised to every behaviour or population, but it demonstrates how rapidly intention and execution can separate when measured at the moment action is supposed to occur.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/28155108/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Momentary assessment of physical activity intention-behavior coupling in adults - PubMed...</span></span></span>

A later study using 2,341 momentary assessments found a smaller but still clear gap: intended [physical activity]({{ 'physical-capacity/' | relative_url }}) was not carried out in about a quarter of relevant episodes. More specific planning, stronger self-efficacy and intrinsic motivation all increased the probability that an intention became action.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/article/pii/S1469029223000699" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[ScienceDirect]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Within-person association of volitional factors and physical activity: Insights from an ecological momentary assessment stud...</span></span></span> The important point is not that intentions are weak or useless. It is that an intention leaves several practical problems unresolved.

That is why planning can outperform simply trying to intensify desire. **Implementation intentions** specify a response to a future situation: “If situation X occurs, I will do Y.” A major meta-analysis of 94 independent tests found a medium-to-large average effect on goal attainment, while a separate meta-analysis found that implementation intentions improved prospective memory — remembering to carry out intended future actions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/article/abs/pii/S0065260106380021" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[ScienceDirect]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Implementation Intentions and Goal Achievement: A Meta‐analysis of Effects and Processes - ScienceDirect...</span></span></span> These plans do not manufacture endless motivation. They reduce how much has to be decided at the critical moment.

## Motivation changes from day to day

Treating motivation as a stable personal resource creates a second problem: **the same person does not have the same motivational state every day**. Energy, mood, competing rewards, stress, perceived effort and the attractiveness of an outcome can all change between occasions.

Recent intensive longitudinal research measured motivation repeatedly in everyday life rather than treating it as a fixed personality characteristic. In a 15-day study involving 3,344 momentary assessments, researchers found substantial within-person fluctuations in motivation. Those momentary states predicted willingness to exert effort over and above participants' more stable motivational characteristics. Higher state motivation increased sensitivity to prospective rewards and made effortful choices more attractive.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC11962463/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

Physical-activity research shows a similar pattern. Momentary desire for activity varies across the day, rather than remaining fixed at the level captured by a one-off questionnaire.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/article/pii/S146902922300047X" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[ScienceDirect]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Open source on sciencedirect.com.</span></span></span> This matters for self-improvement because a plan that works only when the desired behaviour feels appealing is exposed to every downward fluctuation.

Consider two approaches to evening study. One person relies on the thought, “I will revise when I feel sufficiently motivated.” Another has already chosen a 20-minute task, placed the materials on the desk and linked starting to finishing dinner. Both may value the qualification equally. The second arrangement simply leaves fewer parts of execution dependent on how attractive studying happens to feel at 7.30 pm.

This is not an argument for ignoring the **quality** of motivation. Self-determination research distinguishes relatively autonomous motivation — acting because something is valued or intrinsically rewarding — from behaviour driven mainly by external pressure. A systematic review of 66 exercise studies found more autonomous forms of motivation consistently associated with exercise participation; there was also evidence that intrinsic motivation may become particularly important for longer-term adherence.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/22726453/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span> A 2025 review of reviews likewise found competence, intrinsic regulation and identified regulation positively associated with physical activity.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/40256835/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

But this strengthens rather than overturns the main point. Motivation has **degrees and qualities**, and [better motivation]({{ 'better-motivation/' | relative_url }}) improves the odds of persistence. It still does not remove the execution problem. In a meta-analysis of 65 independent tests, interventions based on self-determination theory produced a statistically significant but small average effect on health behaviour, about d=.23, with autonomous motivation and perceived competence helping to explain behavioural improvement.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/32437175/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span> Motivation is one mechanism in sustained action, not a substitute for all the others.

## Build for low-motivation moments

The practical test of a self-improvement system is therefore not whether it feels inspiring on the day it is designed. It is whether the intended behaviour remains easy enough to initiate when enthusiasm is ordinary or low.

One way to reduce motivational dependence is to attach behaviour to **predictable cues**. Habit research describes habits as learned associations through which recurring contexts can activate responses with relatively little deliberate thought. Once such associations become strong, action need not be reconstructed from motivation and conscious decision-making on every occasion.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/26361052/?dopt=Abstract" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-title">Pub Med Psychology of Habit</span><span class="citation-popover-snippet">Pub Med Psychology of Habit</span></span></span>

The transition is important: motivation often helps create the repetitions from which a habit can develop, but greater [automaticity]({{ 'automaticity/' | relative_url }}) can subsequently make repeated performance less sensitive to motivational variation. Reviews therefore caution against presenting habit as a magical replacement for motivation. A new behaviour still has to be initiated and repeated before it can become reliably cue-driven, and evidence for the long-term effects of habit-focused interventions remains less complete than popular accounts sometimes suggest.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://academic.oup.com/edited-volume/62246/chapter-abstract/550940636" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: academic.oup.com">[OUP Academic]</a><span class="citation-popover" role="note"><span class="citation-popover-source">academic.oup.com</span><span class="citation-popover-snippet">Open source on oup.com.</span></span></span>

Stable contexts appear useful during that process. In a six-week study of new study behaviours, participants asked to repeat their actions in more stable contexts developed greater automaticity and achieved more of their repetition goals than those operating in variable contexts. An accompanying observational dataset showed the same general pattern.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC9226889/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span> More recently, a randomised study of 127 insufficiently active adults compared people planning walks in consistent contexts with people planning in varied contexts. Both increased walking during the intervention, but only the consistent-context group developed and maintained the predicted increase in automaticity.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/39225981/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

The evidence is not perfectly uniform. An ecological momentary study of older adults found associations between some forms of context stability and physical or sedentary activity, but did not find that measured habit strength consistently explained those relationships.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/33502088/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span> That is a useful restraint on simplistic advice: merely doing something at “the same time every day” does not guarantee that it will become effortless. Behaviours differ in complexity, environments change, and relevant cues can be highly individual.

For low-motivation moments, the most defensible supports are therefore modest ones that reduce the number of things motivation must accomplish:

* **Specify the trigger.** Replace “I will do it later” with a recognisable event or situation: after breakfast, after closing the work laptop, or when arriving at the library. Implementation-intention research supports this shift from general intention to a situation-linked response.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/article/abs/pii/S0065260106380021" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[ScienceDirect]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Implementation Intentions and Goal Achievement: A Meta‐analysis of Effects and Processes - ScienceDirect...</span></span></span>
* **Shrink the starting requirement.** A smaller [first action]({{ 'first-action/' | relative_url }}) reduces the immediate effort cost. The goal is not to claim that tiny actions automatically create major outcomes, but to make initiation less vulnerable to a temporary motivational dip.
* **Prepare before motivation is needed.** Put required materials where the behaviour will occur, remove unnecessary steps and resolve predictable decisions in advance. Modern habit research emphasises cues and friction because established behaviour is strongly shaped by the context in which choices occur.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.psychologicalscience.org/journals/current-directions/09637214241246480/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: psychologicalscience.org">[Association for Psychological Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">psychologicalscience.org</span><span class="citation-popover-snippet">Open source on psychologicalscience.org.</span></span></span>
* **Use [consistency]({{ 'consistency/' | relative_url }}) where it is realistic.** Repeating an action in a stable situation can make the context itself increasingly useful as a prompt.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC9226889/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>
* **Keep the behaviour connected to a reason you actually endorse.** Systems should reduce dependence on momentary enthusiasm, not turn the goal into meaningless compliance. Evidence on autonomous motivation indicates that personally valued or enjoyable reasons remain helpful for sustained participation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC3441783/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

These supports change the role motivation plays. Instead of requiring motivation to generate a fresh decision, overcome every obstacle and launch the behaviour each time, motivation can do the work for which it is better suited: establishing that the goal matters, helping select an appropriate course of action and periodically prompting reconsideration when the system no longer serves the goal.

## Aim for reliability, not permanent enthusiasm

The popular ideal of long-term self-improvement often imagines a person becoming steadily more motivated until good behaviour feels natural every day. The evidence points to a less dramatic and more useful model. Motivation can deepen, weaken and fluctuate; intentions can be sincere without being enacted; and even interventions that successfully strengthen motivation tend to produce smaller changes in actual behaviour.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/16536643/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Does changing behavioral intentions engender behavior change? A meta-analysis of the experimental evidence - PubMed...</span></span></span>

The better target is **reliable execution despite normal variation in motivation**. That means retaining reasons that feel personally worthwhile while transferring some control of behaviour to advance decisions, identifiable cues, prepared environments and repeated routines. Implementation intentions help bridge moments between wanting and doing, while stable repetition can sometimes allow action to become more automatic.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/article/abs/pii/S0065260106380021" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[ScienceDirect]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Implementation Intentions and Goal Achievement: A Meta‐analysis of Effects and Processes - ScienceDirect...</span></span></span>

Motivation still matters most at important junctions: choosing a goal, beginning a difficult change, recovering after disruption and deciding whether a routine remains worth maintaining. What it does not need to do is carry the entire behavioural load every day. In self-improvement that lasts, the strongest system is not the one that assumes tomorrow's motivation will be high. It is the one designed so that tomorrow's motivation does not have to be.

    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
