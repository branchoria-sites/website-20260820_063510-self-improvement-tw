## Introduction

A minimum workout start is the smallest pre-decided action that counts as **beginning** a planned [exercise]({{ 'exercise/' | relative_url }}) session on a difficult day. It is not a miniature fitness target and it does not need to deliver the benefits of the full workout. Its job is narrower: when motivation is low, make the threshold for responding to the usual exercise cue small enough that starting remains realistic.



<figure class="article-media-figure article-media-figure-illustration"><img src="{{ "/assets/images/self_improvement_tha_c01280_exercise_systems_edd719_minimum_workout_star_f013c0-Illustration-1-dark.svg" | relative_url }}" alt="Minimum Start illustration 1" data-theme-src-dark="{{ "/assets/images/self_improvement_tha_c01280_exercise_systems_edd719_minimum_workout_star_f013c0-Illustration-1-dark.svg" | relative_url }}" data-theme-src-light="{{ "/assets/images/self_improvement_tha_c01280_exercise_systems_edd719_minimum_workout_star_f013c0-Illustration-1-light.svg" | relative_url }}" width="1920" height="1080" loading="lazy" decoding="async" fetchpriority="low"><figcaption class="article-media-caption"><span class="article-media-caption-label">Explanatory illustration 1</span></figcaption></figure>

For a walker, that might mean putting on walking shoes and going outside for five minutes. For a runner, it could mean changing into running kit and beginning an easy five-minute warm-up. For strength training, it might mean setting up and completing the first warm-up set. After that minimum has been completed, continuing is optional.

This distinction matters because research on exercise habits suggests that **instigating a workout and executing the workout are different behavioural problems**. The evidence does not establish a scientifically optimal five-minute, one-set or one-kilometre minimum. Instead, it supports a practical policy: define the start separately from the performance standard, keep that start easy to execute under predictable barriers, and allow the full session to remain the goal without making it the price of beginning.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/26148187/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Habitual exercise instigation (vs. execution) predicts healthy adults&#x27; exercise frequency - PubMedJanuary 1, 2016...</span><span class="citation-popover-meta">Published: January 1, 2016</span></span></span>

## Separate starting criteria from performance criteria

The most useful way to set a minimum is to maintain **two standards rather than lowering one standard**.

The **starting criterion** answers: *What do I have to do when my exercise cue occurs for this routine to have begun?* The **performance criterion** answers: *What workout am I normally trying to complete?* On an ordinary day, the two flow together. On a difficult day, they can separate.

Suppose Tuesday's planned workout is a 40-minute run. The performance criterion can remain 40 minutes while the minimum start is simply: change into running clothes, leave the house and run or walk easily for five minutes. Reaching five minutes does not magically make a five-minute outing equivalent to the planned run. It means the person has successfully carried out the **start policy**. At that point, they can continue, shorten the session or stop.

That distinction fits an important finding from exercise-habit research. In a study of 123 healthy adults who reported exercise through daily electronic diaries for a month, L. Alison Phillips and Benjamin Gardner distinguished **instigation habit** — automatically deciding or preparing to exercise — from **execution habit**, the automatic performance of the exercise sequence itself. Instigation habit was the only unique habit predictor of exercise frequency. The study was observational rather than a trial of minimum workouts, so it cannot prove that tiny starts cause better adherence. But it provides a strong reason to treat “getting the workout started” as a behavioural target in its own right.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/26148187/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Habitual exercise instigation (vs. execution) predicts healthy adults&#x27; exercise frequency - PubMedJanuary 1, 2016...</span><span class="citation-popover-meta">Published: January 1, 2016</span></span></span>

Gardner and colleagues subsequently developed the distinction beyond exercise, describing habitual instigation as a cue triggering the selection and initiation of an action, while habitual execution concerns progression through its component actions. Their results again indicated that instigation was more closely associated with behaviour frequency. For a minimum-workout policy, the implication is useful: **standardise the doorway into exercise without requiring the whole workout to be standardised or automatic**.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/26991427/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Habitual instigation and habitual execution: Definition, measurement, and effects on behaviour frequency - PubMed...</span></span></span>

This also explains why “do at least 30 minutes” is often a poor definition of a minimum start. Thirty minutes is a duration target. It says how much exercise to perform, not what observable action constitutes beginning. A better start criterion occurs near the front of the sequence: shoes on and outside; onto the treadmill and moving; at the rack with the warm-up set begun.

## How small should the minimum be?

There is no research-backed universal number of minutes, steps, repetitions or sets that constitutes the ideal minimum workout start. Claims that everyone should use exactly two minutes, five minutes or one set should therefore be understood as rules of thumb rather than established physiological or behavioural thresholds.

A more defensible test is functional: **the minimum should be small enough that you would normally still do it on a low-motivation day, but substantial enough to constitute unmistakable entry into the exercise sequence**. “Think about running” is too early. “Complete the entire programmed run” defeats the purpose. “Put on my kit, go outside and start the warm-up” sits between them.

Planning research provides support for making this response concrete. A 2022 systematic review and meta-analysis covering 41 randomised trials, with 35 included in the meta-analysis, found that [physical-activity]({{ 'physical-capacity/' | relative_url }}) planning interventions produced a small-to-moderate improvement in activity compared with control conditions. These interventions typically specify when, where or how action will occur; some also use [coping plans]({{ 'coping-plans/' | relative_url }}) for anticipated barriers. An earlier systematic review likewise concluded that implementation-intention approaches appeared to promote physical activity, particularly when plans addressed obstacles. Neither literature specifically validates “minimum workouts”, but both support deciding the response to a difficult situation **before** that situation occurs.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC9223740/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">PubMed Central (PMC)The Effectiveness of Planning Interventions for Improving Physical Activity in the General Population: A Systematic R...</span></span></span>

A useful policy can therefore be written in advance:

> **When my normal workout cue occurs and I strongly want to skip the session, I will complete my minimum start. After completing it, I may stop without treating the day as a failure.**

The last sentence matters. If “five minutes” secretly means “once I start, I must force myself through 45 minutes”, the five-minute rule ceases to be a genuine minimum. It becomes a bargaining tactic whose real cost is still the full workout.

Public-health guidance also makes room for small amounts of activity. The UK Chief Medical Officers state that adults should aim to be active every day, that any activity is better than none and that more is better, while the World Health Organization advises inactive adults to begin with small amounts and gradually increase frequency, intensity and duration. These recommendations concern health-enhancing physical activity rather than habit design, but they help avoid the false conclusion that a shortened session is physically worthless.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.gov.uk/government/publications/physical-activity-guidelines-uk-chief-medical-officers-report/uk-chief-medical-officers-physical-activity-guidelines" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: GOV.UK">[GOV.UK]</a><span class="citation-popover" role="note"><span class="citation-popover-source">GOV.UK</span><span class="citation-popover-title">U K Chief Medical Officers&#x27; physical activity guidelines</span><span class="citation-popover-snippet">UK Chief Medical Officers&#x27; physical activity guidelines - GOV.UKJuly 10, 2026...</span><span class="citation-popover-meta">Published: July 10, 2026</span></span></span>

## Minimum starts for walking, running and strength training

A minimum start works best when it is attached to the **existing cue and normal exercise sequence**. It should not require inventing a second complicated workout for bad days.

For **walking**, a normal plan might be a 30-minute brisk walk after lunch. A workable minimum could be: *put on walking shoes, leave the building and walk for five minutes*. Someone beginning from very low activity might simply walk to a predetermined nearby point and back. NHS guidance explicitly encourages people to start gradually, and current Better Health advice emphasises that every minute counts while people build towards recommended weekly activity levels.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nhs.uk/better-health/get-active/how-to-be-more-active/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nhs.uk">[nhs.uk]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nhs.uk</span><span class="citation-popover-title">How to be more active</span><span class="citation-popover-snippet">Better Health - NHSFebruary 17, 2023...</span><span class="citation-popover-meta">Published: February 17, 2023</span></span></span>

For **running**, the minimum should usually preserve the act of starting without demanding normal pace or distance: *change into running kit, go outside and complete five minutes of easy walking and jogging*. That is preferable to defining success as “run one kilometre as fast as usual”, because intensity adds another performance demand precisely when the policy is intended to reduce the starting threshold. Research on affect during exercise also cautions against assuming harder is always behaviourally better: reviews find that exercise intensity influences pleasure and displeasure, with responses generally becoming less positive at sufficiently demanding intensities and self-selected intensity often producing a more tolerable experience.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/18971508/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

For **strength training**, a minimum might be: *arrive at the training area, perform the normal warm-up and complete the first warm-up or working set of the first programmed exercise*. Another option for a home routine is one deliberately easy set each of two familiar movements. The crucial point is to decide the rule beforehand rather than negotiating repetitions while already tempted to skip.

The minimum should not be confused with a complete strength prescription. NHS guidance recommends muscle-strengthening work involving the major muscle groups on at least two days each week and describes multiple sets as a normal training target. A one-set minimum can therefore function as an **entry criterion** without being presented as an equivalent substitute for a properly designed strength programme.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nhs.uk/live-well/exercise/how-to-improve-strength-flexibility/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nhs.uk">[nhs.uk]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nhs.uk</span><span class="citation-popover-title">How to improve your strength and flexibility</span><span class="citation-popover-snippet">How to improve your strength and flexibility</span></span></span>

Across all three examples, the pattern is the same:


<div class="content-enhancement content-enhancement--benefit" markdown="1">

* **Walking:** begin the actual walk; duration can remain tiny.
* **Running:** begin the normal run sequence; pace and distance can be relaxed.
* **Strength:** begin the normal lifting sequence; total exercises, sets and load can be reduced.
* **Successful minimum:** the specified start happened.
* **Successful full session:** the planned training target was completed.

</div>

Keeping those final two outcomes separate prevents an important accounting error: treating every reduced workout as either a complete failure or a complete substitute for normal training.

## Continuing is a bonus, not a hidden requirement

A minimum start often creates an opportunity to continue. Once someone is dressed, outside and moving, several barriers to exercise have already disappeared. But the policy becomes more robust if continuation is treated as an **option rather than an obligation**.

There is a behavioural reason for this restraint. Exercise-habit research suggests that simple, consistent initiation deserves particular attention, while research with new gym members has associated [consistency]({{ 'consistency/' | relative_url }}), lower behavioural complexity, environmental factors and positive affective judgements with stronger habit development. The latter study followed 111 new gym members for 12 weeks and found that frequent repetition was associated with habit formation; it should not be read as establishing a universal timetable for forming an exercise habit, but it reinforces the value of repeatable, uncomplicated behaviour.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/25851609/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-title">Pub Med Exercise habit formation in new gym members: a longitudinal study</span><span class="citation-popover-snippet">Pub Med Exercise habit formation in new gym members: a longitudinal study</span></span></span>

There is also a motivational reason. How exercise feels can influence subsequent exercise behaviour. Reviews of the exercise-affect literature have linked more positive affective responses with better prospects for adherence, while finding meaningful differences according to intensity and individual experience. A minimum-start system that repeatedly turns an exhausted person's five-minute commitment into a compulsory punishing workout risks teaching the opposite lesson from the one intended: that beginning exercise carries an unpredictable and unpleasant cost.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/18971508/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

This does not mean stopping at the minimum whenever exercise becomes mildly uncomfortable. On ordinary days, the planned session remains the target. The distinction is that the **low-motivation fallback has a genuine stopping point**. If energy improves after the warm-up, continue. If the original barrier still matters after the minimum — an exceptionally demanding day, poor sleep, limited time or simply an unusually difficult start — the minimum can remain the whole session.

## When the minimum should stay small

The purpose of a minimum start is easily lost through gradual expansion. Five minutes becomes ten; one set becomes three; “just put your shoes on and walk outside” becomes “and you may as well complete the usual route”. Eventually the fallback becomes demanding enough that it no longer solves the original problem.

Keep the minimum deliberately small when **the main problem is initiation**. If you routinely complete the full workout once you begin, making the minimum larger adds little. The bottleneck is crossing the threshold, so the policy should concentrate there.

Keep it small when **the day is genuinely constrained**. A fallback is particularly useful because real barriers are not identical. Coping-planning research treats barriers as situations for which responses can be specified in advance. A minimum start is one possible response to the barrier “I have little motivation or time today”; it should not pretend that the barrier has disappeared.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC6235272/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">PubMed Central (PMC)Impact of implementation intentions on physical activity practice in adults: A systematic review and meta-analysis of...</span></span></span>

Keep it small when **expansion would make you hesitate to start**. This is perhaps the simplest diagnostic. If you readily begin when the rule is “five easy minutes” but begin bargaining with yourself when it becomes “at least 20”, the larger threshold is performing a different job. Put the additional 15 minutes back on the performance side of the boundary.

And keep it small enough that it does not compete with the full programme. The minimum is a fallback for preserving the act of starting; it is not a rationale for permanently replacing progressive training with token activity. UK guidance still recommends adults accumulate at least 150 minutes of moderate activity, 75 minutes of vigorous activity or an appropriate combination each week, alongside muscle-strengthening activity on at least two days. “Any activity is better than none” and “more is better still” belong together.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.gov.uk/government/publications/physical-activity-guidelines-uk-chief-medical-officers-report/uk-chief-medical-officers-physical-activity-guidelines" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: GOV.UK">[GOV.UK]</a><span class="citation-popover" role="note"><span class="citation-popover-source">GOV.UK</span><span class="citation-popover-title">U K Chief Medical Officers&#x27; physical activity guidelines</span><span class="citation-popover-snippet">UK Chief Medical Officers&#x27; physical activity guidelines - GOV.UKJuly 10, 2026...</span><span class="citation-popover-meta">Published: July 10, 2026</span></span></span>

## A minimum that actually works

The best minimum is therefore not the smallest action imaginable. It is the **smallest credible beginning of the real exercise behaviour** that remains easy enough to perform when willingness is unusually low.

It should have four properties: it starts after the same recognisable cue as the normal workout; it specifies an observable action rather than a vague intention; it is substantially easier than the full performance target; and completing it genuinely gives permission to stop. Those features turn “I should at least do something” into a policy that can be executed without another round of negotiation.

That is the larger value of a minimum workout start within a cue-and-convenience exercise routine. The full workout still matters for fitness. The minimum serves a different purpose: **protecting the transition from cue to action on precisely the days when demanding full performance before you have even begun makes starting least likely**. The research base is stronger for exercise instigation, planning, gradual progression and the value of some activity than it is for any particular “tiny workout” formula. A sensible minimum uses those findings without pretending that five minutes, one set or any other convenient number is a scientifically established magic threshold.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/26148187/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[nih.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Habitual exercise instigation (vs. execution) predicts healthy adults&#x27; exercise frequency - PubMedJanuary 1, 2016...</span><span class="citation-popover-meta">Published: January 1, 2016</span></span></span>

    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
