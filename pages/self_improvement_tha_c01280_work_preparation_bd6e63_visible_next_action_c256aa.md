## Introduction

A useful end-of-day restart note should make tomorrow’s first move executable, not merely remind you that a project exists. “Continue report” preserves the project name; “Open the survey workbook, filter to July respondents, and check whether the age totals match Table 3” preserves an action. The second version matters because it reduces the amount of project reconstruction required before useful work can resume.

Several strands of research support this approach, although there is not a large research literature testing “restart notes” as a named productivity technique. Experiments on interrupted work show that preparing for resumption and preserving useful contextual cues can shorten the disruption caused by a break. Research on implementation intentions finds that specifying what action will happen in response to a future cue improves goal initiation. Studies of external reminders likewise show that [remembering]({{ 'remembering/' | relative_url }}) improves when an intention is stored in the environment rather than left entirely to memory.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/article/pii/S1071581903000235" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[sciencedirect.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Preparing to resume an interrupted task: effects of prospective goal encoding and retrospective rehearsal - ScienceDirect...</span></span></span>

The practical policy is therefore simple: **before stopping unfinished work, leave one visible instruction describing the first physical or digital action you expect to perform when you return.**

## Turning broad tasks into visible actions

The crucial distinction is between a **project description** and a **restart instruction**. “Finish budget”, “work on presentation” and “deal with supplier problem” describe desired outcomes. They still force tomorrow’s worker to determine where to begin. A restart instruction moves that decision to today, while the project’s state is still readily available in memory.

Research on implementation intentions provides the clearest general model. Peter Gollwitzer and Paschal Sheeran’s meta-analysis examined 94 independent tests of plans that connect a specified future situation with a specified response — essentially deciding in advance, “when this happens, I will do that”. Across the studies, implementation intentions had a medium-to-large overall effect on goal attainment and specifically helped with initiating goal-directed behaviour.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/chapter/bookseries/abs/pii/S0065260106380021" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[ScienceDirect]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Implementation Intentions and Goal Achievement: A Meta‐analysis of Effects and Processes - ScienceDirect...</span></span></span>

A restart note need not be a formal if–then statement, but it can exploit the same principle. Compare:

> Tomorrow: work on quarterly analysis.

with:

> When I reopen this workbook: check the three missing March values against the raw export.

The latter has already settled the first behavioural choice. It identifies both the cue — reopening the workbook — and the response. Importantly, this does **not** mean planning tomorrow’s entire session. The intervention is deliberately smaller: decide the [first action]({{ 'first-action/' | relative_url }}) while the information needed to make that decision is still fresh.

Interruption research makes this especially relevant to unfinished knowledge work. In an experiment by J. Gregory Trafton and colleagues, participants who received a short warning before an interruption used that interval to prepare and subsequently resumed the suspended task more quickly than participants interrupted immediately. The researchers distinguished between remembering the state of the task and encoding what should be done when work resumed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/article/pii/S1071581903000235" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[ScienceDirect]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Preparing to resume an interrupted task: effects of prospective goal encoding and retrospective rehearsal - ScienceDirect...</span></span></span>

Helen Hodgetts and Dylan Jones found a related effect: preparation before interruption reduced resumption costs, while contextual cues helped people retrieve suspended goals. Altering those cues after the interruption made recovery harder.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/16938050/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Contextual cues aid recovery from interruption: the role of associative activation - PubMed...</span></span></span> These were laboratory tasks rather than overnight office projects, so the findings should not be treated as a direct trial of end-of-day notes. They do, however, support the underlying design principle: **preserve the information tomorrow will need to recover the suspended goal.**

## What should tomorrow’s first action look like?

A strong next action has three characteristics: it is observable, it points to the relevant object or location, and it is small enough to start without another round of planning. “Think about the problem” usually fails this test because the worker must still decide what thinking consists of. “List the three explanations that could account for the discrepancy” passes it.

The action should normally begin with a concrete verb: open, compare, rewrite, test, call, check, extract, insert, send, reconcile or review. The point is not linguistic neatness. A concrete verb forces the note writer to decide what tomorrow’s behaviour actually is.

There is useful evidence that the *content* of reminders matters. In experiments on prospective memory — remembering to perform an intended future action — researchers compared reminders containing different information. Reminders that specified both the target cue and the associated action improved prospective-memory performance, whereas target-only or action-only reminders did not produce the same benefit in one experiment. The benefits of reminders were also greater under heavier memory loads.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/36201804/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Benefits from prospective memory offloading depend on memory load and reminder type - PubMedOctober 6, 2022...</span><span class="citation-popover-meta">Published: October 6, 2022</span></span></span>

That finding maps neatly onto restart notes. “Table 3” identifies a target but not what to do with it. “Check totals” identifies an action but not where. “Table 3: check its totals against the July export” carries both pieces.

A practical test is to imagine encountering the note tomorrow after having forgotten most of today’s working context. **Could you obey it immediately?** If the answer is “I would first need to work out what I meant”, the note is not finished.

## Examples across everyday knowledge work

The right level of specificity depends on the work, but the underlying transformation is consistent: replace a broad intention with the first manipulable object and action.


<div class="content-enhancement content-enhancement--example" markdown="1">

* **Writing:** Instead of “continue methods section”, leave “Rewrite the sampling paragraph using the three figures highlighted in Smith; then add the citation.”
* **Analysis:** Instead of “investigate conversion decline”, leave “Filter the weekly conversion table to mobile traffic and compare weeks 27–30 with the same weeks last year.”
* **Coding:** Instead of “fix login bug”, leave “Run the failing `expired_token` test, inspect the refresh-token branch, and confirm whether the exception occurs before the retry.”
* **Administration:** Instead of “sort invoices”, leave “Open the August invoice folder and match the five unassigned payments against the bank export.”
* **Presentation work:** Instead of “finish slides”, leave “Replace the placeholder chart on slide 8 with the regional revenue chart and check that its date range ends in July.”
* **Research:** Instead of “read papers on retention”, leave “Read the results section of the saved retention paper and record its sample size, outcome measure and effect estimate in the evidence table.”

</div>

These instructions are intentionally modest. They do not attempt to specify every subsequent action. Once work is moving, the next decision can often be made with the project open and its context restored. The restart note is aimed at the unusually fragile transition between *not working on the project* and *working on it again*.

That distinction also prevents a restart note from turning into elaborate daily planning. Research on workplace planning suggests that planning can support daily performance, but its effects depend on the work environment and interruptions. A two-week experience-sampling study, for example, distinguished ordinary time-management planning from contingent planning for anticipated interruptions and found different relationships with engagement and performance.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/29154579/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">When daily planning improves employee performance: The importance of planning type, engagement, and interruptions - PubMedNovember...</span></span></span> The narrower restart-note practice does not require predicting tomorrow’s whole day; it merely pre-decides the opening move.

## Make the instruction visible where work resumes

Writing a good action is only half the intervention. It should appear where it can actually trigger behaviour.

Prospective-memory researchers call the use of external reminders **intention offloading**: instead of depending entirely on internal memory, people put information into the environment. Sam Gilbert’s experiments involving 1,196 participants found that setting external reminders improved performance. People also used reminders more when memory demands were greater or interruptions were expected.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://journals.sagepub.com/doi/10.1080/17470218.2014.972963" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: journals.sagepub.com">[Sage Journals]</a><span class="citation-popover" role="note"><span class="citation-popover-source">journals.sagepub.com</span><span class="citation-popover-snippet">Sage JournalsStrategic offloading of delayed intentions into the external environment - Sam J. Gilbert, 2015May 1, 2015...</span><span class="citation-popover-meta">Published: May 1, 2015</span></span></span> A later review concluded that intention offloading is highly effective and that decisions about using reminders are strongly influenced by people’s judgements about their own memory.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC9971128/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">PubMed Central (PMC)Outsourcing Memory to External Tools: A Review of ‘Intention Offloading’ - PMC...</span></span></span>

For work, visibility can be extremely literal. Put the instruction at the top of the draft, in a comment beside the unfinished code, on a sticky note attached to the relevant papers, in the task that will be opened first, or in a text file sitting beside the dataset. The best location is usually **inside or immediately beside the object on which the action will be performed**.

That matters because a generic reminder such as “remember project X” may successfully remind you that something requires attention while still failing to restore what you intended to do. Experimental work on reminders reinforces this distinction: reminders carrying both the relevant cue and intended response can outperform incomplete reminders.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/36201804/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Benefits from prospective memory offloading depend on memory load and reminder type - PubMedOctober 6, 2022...</span><span class="citation-popover-meta">Published: October 6, 2022</span></span></span>

Visibility should therefore be judged functionally, not aesthetically. A beautifully organised note buried three folders deep is a poor cue. An inelegant comment at the exact point where tomorrow’s work begins may be much better.

## How much detail does a restart note actually need?

The ideal note is not the shortest possible note. It is the **shortest note that prevents reconstruction**.

For straightforward work, one sentence may be enough:

> Next: compare the revised forecast with the finance version and investigate any difference above £5,000.

For a cognitively dense task, preserving one or two pieces of state may be worthwhile:

> Next: test whether excluding the two late responses removes the significance. Current model is column H; do not use column G because it still contains the old weighting.

The second sentence is useful because it records information that would otherwise have to be rediscovered. But a miniature project diary would go too far. If the note contains the whole history of the problem, several alternative plans and a long explanation of why each matters, tomorrow begins with reading rather than doing.

A good rule is to record only information needed to cross the restart boundary:


<div class="content-enhancement content-enhancement--step-flow" markdown="1">

1. **Where:** the file, section, record, function, person or physical material involved.
2. **What:** the first observable action.
3. **Critical state, if necessary:** one fact that prevents a likely mistake or repeated investigation.

</div>

Research on memory for interrupted goals helps explain this economy. Models of task resumption emphasise that suspended goals compete with other information and that contextual cues can assist retrieval. Longer or more cognitively demanding interruptions have also been associated experimentally with longer resumption times.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://doi.org/10.1207/s15516709cog2601_2" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: doi.org">[DOI]</a><span class="citation-popover" role="note"><span class="citation-popover-source">doi.org</span><span class="citation-popover-title">Memory for goals: an activation‐based model</span><span class="citation-popover-snippet">Memory for goals: an activation‐based model - Altmann - 2002 - Cognitive Science - Wiley Online LibraryJanuary 1, 2002...</span><span class="citation-popover-meta">Published: January 1, 2002</span></span></span> Overnight, the intervening “interruption” includes everything from commuting and dinner to sleep and the next morning’s messages. Expecting tomorrow’s mind to preserve every detail unaided is an unnecessary gamble when a few words can carry the crucial state forward.

## Stop while the next move is still obvious

The best time to create the note is immediately before leaving the work, not later in the evening. At that moment, you still know why a number looks suspicious, which paragraph is weak, which test failed and what you intended to try next. That transient knowledge is exactly what tomorrow may otherwise have to reconstruct.

Laboratory interruption studies provide a useful analogue. Giving people a brief opportunity to prepare before switching away from a task improved subsequent resumption, and experiments on contextual cues likewise found benefits from encoding useful retrieval information before the break.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/article/pii/S1071581903000235" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[ScienceDirect]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Preparing to resume an interrupted task: effects of prospective goal encoding and retrospective rehearsal - ScienceDirect...</span></span></span> The implication is not that every workday should end with a formal shutdown ritual. It is that the few seconds before disengagement are unusually valuable for preserving the project’s next state.

There may also be an after-hours benefit to making the plan concrete. E. J. Masicampo and Roy Baumeister found across several studies that unfinished goals could produce intrusive thoughts and interfere with unrelated activity, while forming specific plans for those goals eliminated the observed cognitive interference effects. Their experiments do not establish that a one-line restart note will reliably stop work-related rumination, but they do suggest that an unfinished goal and an unfinished goal with a credible plan are psychologically different states.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/21688924/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

The useful stopping question is therefore not “What do I need to remember about this project?” It is narrower: **“If I returned with only this note, what instruction would let me make the first correct move?”**

Write that instruction, put it where the work will resume, and stop. Tomorrow can begin with execution rather than reconstruction.

      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
