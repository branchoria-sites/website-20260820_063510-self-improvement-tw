## Introduction

For a recurring habit, the most useful record is often the smallest one that can answer the question you will actually ask later: **did I do the planned behaviour on this occasion, or not?** A tick beside Monday’s walk, a yes/no entry after language practice, or a marked square for taking a daily medication creates evidence without requiring a miniature research project.

That simplicity is not a claim that more data are always useless. It is a rule about matching the record to the decision. If the goal is “practise guitar after dinner on Monday, Wednesday and Friday”, duration, mood and difficulty may add little to the first adherence question. Three planned occasions require three answers. Research on progress monitoring broadly supports recording behaviour, while habit-formation studies routinely use simple daily occurrence measures because repetition in a stable context is itself important information.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/26479070/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Does monitoring goal progress promote goal attainment? The important qualification is that the evidence specifically comparing **binary habit trackers** with richer tracking systems is limited. The stronger evidence supports self-monitoring in general; studies using tick sheets and yes/no diaries show that binary recording is a workable implementation of that principle, not that a tick box is universally superior.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC7429262/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">PubMed Central (PMC)Self-regulatory behavior change techniques in interventions to promote healthy eating, physical activity, or weight l...</span></span></span>

## What binary tracking captures well

Binary tracking works best when the intended behaviour has a clear definition and a clear opportunity. “Read for ten minutes before bed” can become a yes/no question. “Be more intellectual” cannot. The tracker therefore needs a behavioural threshold established in advance: what counts as done, and on which occasions is it supposed to happen?

That produces a particularly legible measure of **adherence**. If the plan called for four sessions this week and three happened, the record says 3/4. If the behaviour was planned every weekday and the ticks repeatedly disappear on Fridays, the pattern is visible without reconstructing the week from memory. This is the distinctive value of a binary record: it preserves the occurrence pattern while discarding details that may not be needed.

There is good reason to treat recording as more than clerical work. Harkin and colleagues' meta-analysis covered 138 experimental studies and 19,951 participants. Interventions designed to increase monitoring increased goal attainment overall, and effects were larger when monitoring information was physically recorded. The review concerns progress monitoring broadly rather than tick-box habit trackers specifically, so it cannot establish that binary tracking is the optimal format. It does support the underlying policy of turning progress into an external record instead of relying entirely on recollection.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/26479070/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Does monitoring goal progress promote goal attainment? A meta-analysis of the experimental evidence - PubMedFebruary 1, 2016...</span><span class="citation-popover-meta">Published: February 1, 2016</span></span></span>

Habit research provides a more concrete example. In Phillippa Lally and colleagues' well-known 12-week field study, 96 volunteers selected an eating, drinking or activity behaviour to repeat daily in a consistent context and recorded whether they had performed it. Repetition was associated with increasing [automaticity]({{ 'automaticity/' | relative_url }}), although the rate varied greatly between individuals. Crucially, missing one opportunity did not materially derail the habit-formation process. That finding is useful when reading a tick-box record: an empty square is information about one missed repetition, not evidence that the entire effort has failed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Wiley Online LibraryHow are habits formed: Modelling habit formation in the real world - Lally - 2010 - European Journal of Social Psycho...</span></span></span>

Later habit studies have continued to use binary behaviour measures. A longitudinal field study published in *Frontiers in Psychology*, for example, asked participants each day whether they had performed their chosen behaviour and whether they had done so in their chosen context. A 2023 study of fruit-consumption habits similarly used yes/no diary entries to record whether participants ate fruit after a designated meal. These designs illustrate exactly what binary measurement can preserve: **whether the behaviour occurred and, when relevant, whether it occurred in the intended cueing context**.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2020.00560/full" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: frontiersin.org">[Frontiers]</a><span class="citation-popover" role="note"><span class="citation-popover-source">frontiersin.org</span><span class="citation-popover-snippet">FrontiersFrontiers &#124; How to Form Good Habits? A Longitudinal Field Study on the Role of Self-Control in Habit FormationMarch 27, 2020...</span><span class="citation-popover-meta">Published: March 27, 2020</span></span></span>

For ordinary self-improvement, that suggests a compact rule: track the smallest unit that corresponds to the commitment. “Floss after brushing at night” needs one daily box. “Strength train three times each week” needs a record of the three intended sessions. “Study Spanish for 20 minutes after breakfast” can be recorded as done only when the predefined minimum is reached. The simplicity comes from deciding what counts beforehand, not from making the standard vague.

## When extra metrics add little value

Tracking systems easily accumulate fields: duration, intensity, quality, difficulty, mood, location, streak length, notes and numerical scores. Each can be useful for a particular question. But collecting information merely because it *might* become interesting later changes the tracker from an adherence record into a data-collection project.

For a stable recurring behaviour, extra metrics add little when they would not change the next decision. Imagine a person whose immediate objective is simply to establish three weekly gym visits. If a 25-minute session and a 50-minute session both satisfy the current commitment, exact duration may be secondary. The first useful question is whether the planned visits are actually happening. Once that becomes reliable, training volume or progression may deserve separate measurement.

This “minimum sufficient record” approach has indirect empirical support, although the evidence should not be overstated. In a small randomised pilot involving 72 adults, researchers compared standard calorie logging with a simplified system that monitored high-calorie foods. After six months, the groups did not differ significantly in dietary tracking days, dietary intake or weight loss; 43.2% of the standard-monitoring group and 42.9% of the simplified group achieved at least 5% weight loss. The intervention was about weight management rather than habit tick boxes, but it demonstrates an important principle: more detailed recording does not automatically produce a better outcome, and lower-information monitoring can sometimes remain useful.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC9469733/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">PubMed Central (PMC)A pilot randomized trial of simplified versus standard calorie dietary self-monitoring in a mobile weight loss interv...</span></span></span>

The broader evidence is appropriately cautious. A meta-review covering 30 previous meta-analyses and 409,185 participants found inconsistent evidence about individual self-regulation techniques, including self-monitoring, across diet, [physical activity]({{ 'physical-capacity/' | relative_url }}) and weight interventions. The authors also stressed methodological problems with trying to isolate individual techniques from complex, multi-component interventions. Binary tracking should therefore be treated as a practical implementation choice, not as a scientifically proven shortcut that guarantees behaviour change.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/31973666/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

Nor is it safe to assume that every additional question necessarily destroys adherence. Reviews of ecological momentary assessment — repeated questionnaires completed during daily life — find high average compliance despite substantial variation in assessment schedules. One meta-analysis of 477 articles reported average compliance of about 79%, while another systematic review found insufficient consistent evidence to identify a simple relationship between overall assessment burden and compliance. The case for a tick box is therefore primarily one of **information economy**: do not collect variables that have no present use, rather than assuming that every extra tap is demonstrably harmful.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/33656451/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

## Make “done” unambiguous

The chief weakness of binary tracking is also obvious: two states cannot preserve distinctions that matter. A tick can make a two-minute token effort look identical to a substantial session unless the rule defining completion prevents that problem.

A useful binary tracker therefore needs three things settled before the week begins:


<div class="content-enhancement content-enhancement--example" markdown="1">

* **The behaviour:** what action is being tracked — for example, “practise vocabulary”.
* **The minimum:** what qualifies as completion — for example, “complete the planned 15-minute session”.
* **The occasion:** when it is expected — for example, “after breakfast on weekdays”.

</div>

That formulation makes the record interpretable. A blank square means the specified action did not happen on that intended occasion; a tick means it met the agreed threshold. It avoids negotiating retrospectively with the tracker — counting a vaguely related action because the day is ending and an unbroken run of ticks looks appealing.

Context can matter particularly during habit formation. Habit theory treats repeated performance in a consistent context as important because environmental or situational cues can become associated with the response. Lally and Gardner's review describes habits as automatic behavioural responses to cues that develop through repetition in consistent contexts. A binary tracker can accommodate that without becoming complicated: instead of recording “meditated today”, the criterion can be “meditated after morning coffee”.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.tandfonline.com/doi/full/10.1080/17437199.2011.603640" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tandfonline.com">[Taylor &amp; Francis Online]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tandfonline.com</span><span class="citation-popover-snippet">Open source on tandfonline.com.</span></span></span>

There is also no strong scientific reason to make an uninterrupted streak the primary score. Lally's field study found that a single missed opportunity did not materially affect the habit-formation process. A tracker that turns one blank square into “back to zero” can therefore impose a psychological interpretation that the underlying repetition evidence does not require. Counting completed opportunities over a meaningful period — 16 of 20 planned occasions, for example — preserves more information than treating 15 consecutive successes followed by one miss as zero progress.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Wiley Online LibraryHow are habits formed: Modelling habit formation in the real world - Lally - 2010 - European Journal of Social Psycho...</span></span></span>

## When a richer record is justified

A tick box stops being sufficient when the next useful question cannot be answered from occurrence alone. The right response is not necessarily to abandon binary tracking; it may be to add the **[one variable]({{ 'one-variable/' | relative_url }}) that resolves the new uncertainty**.

Suppose someone reliably completes every scheduled run but wants to improve endurance. “Ran: yes” no longer distinguishes 2 km from 10 km, so distance or duration becomes decision-relevant. If a student consistently ticks “revision completed” but examination performance is stagnant, time spent, material covered or retrieval-test accuracy may reveal what the adherence record cannot. If sleep is the target, “went to bed on time” measures one behaviour but cannot establish sleep duration or quality.

The distinction is between measuring **whether the process occurred** and measuring its **dose, quality or outcome**. Those are different questions. Binary records are strongest for the first.

A richer record is particularly justified when:

* there is meaningful variation among completed sessions that affects the goal;
* safety, symptoms, dosage or other consequential details need accurate records;
* the behaviour occurs many times per day, making “done today” misleading;
* the aim is optimisation rather than basic [consistency]({{ 'consistency/' | relative_url }});
* [repeated misses]({{ 'repeated-misses/' | relative_url }}) need diagnosis, so circumstances or barriers must be recorded;
* an outcome must be tracked separately from the behaviour intended to influence it.

Research on physical-activity interventions illustrates why this distinction matters. One trial analysis separately classified whether participants self-monitored and whether they actually met step- or activity-minute goals. Someone could therefore be monitoring faithfully without attaining the behavioural target. A simple tick is useful only when its meaning is clear: “I recorded my [exercise]({{ 'exercise/' | relative_url }})”, “I exercised”, and “I met my exercise target” are three different binary variables.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/35089159/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

Similarly, a recent systematic review of [feedback]({{ 'feedback/' | relative_url }}) within diet, physical-activity and weight self-monitoring interventions found evidence that feedback could improve physical-activity outcomes, although effects varied by outcome and intervention. Once a record is being used to generate tailored feedback or adjust a programme, richer measurements may become useful precisely because someone intends to act on the additional information.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://doi.org/10.1186/s12966-023-01555-6" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: doi.org">[DOI]</a><span class="citation-popover" role="note"><span class="citation-popover-source">doi.org</span><span class="citation-popover-snippet">Open source on doi.org.</span></span></span>

## The useful record is the one that settles the question

Binary tracking is not a stripped-down version of “proper” tracking. For a clearly defined recurring habit, it can be the measurement that fits the question exactly. If the commitment was to perform a specified action on specified occasions, a sequence of yes/no observations reveals adherence directly.

Its limits should remain equally clear. A tick cannot reveal how hard somebody worked, how well they performed, what caused a miss or whether the behaviour ultimately produced the desired outcome. Those questions require other measurements. The mistake is collecting those measurements automatically rather than because a decision requires them.

For basic recurring habits, the practical policy is therefore economical: **define the behaviour precisely, mark each intended occasion as done or not done, and review the resulting pattern rather than reconstructing it from memory**. Add another metric only when the tick boxes leave an important, actionable question unanswered. That keeps the written record serving the behaviour, rather than allowing the work of maintaining the record to become a second habit project of its own.

    var url = template.replace('{query}', encodeQuery(query || '')).replace('{query_plain}', String(query || ''));
    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
