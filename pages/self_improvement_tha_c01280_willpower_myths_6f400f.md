## Introduction

The idea that inconsistent people simply need “more willpower” is attractive because it turns behaviour into a character story: disciplined people resist temptation; undisciplined people give in. Behavioural research gives a less moralising and more useful account. [Self-control]({{ 'self-control/' | relative_url }}) matters, but success often depends on what happens *before* a difficult choice — which cues are present, how easy each option is, whether a useful response has been repeated in that setting, and whether temptation can be avoided rather than repeatedly defeated.



<figure class="article-media-figure article-media-figure-overview"><img src="{{ "/assets/images/self_improvement_tha_c01280_willpower_myths_6f400f-overview.webp" | relative_url }}" alt="Overview image for The Idea That Inconsistent People Simply Need “more Willpower”" width="1024" height="559" loading="lazy" decoding="async" fetchpriority="low"><figcaption class="article-media-caption"><span class="article-media-caption-label">Illustrative overview</span></figcaption></figure>

This distinction matters for self-improvement because effortful resistance is only one form of self-control. People who are good at pursuing long-term goals do not necessarily spend their days winning heroic internal battles. Studies instead associate effective self-control with encountering fewer problematic temptations, using anticipatory strategies and developing beneficial habits that reduce the amount of inhibition required in the first place.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC4736542/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[nih.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-title">Pub Med Central (PMC)Situational Strategies for Self-Control</span><span class="citation-popover-snippet">PubMed Central (PMC)Situational Strategies for Self-Control - PMCJanuary 1, 2016...</span><span class="citation-popover-meta">Published: January 1, 2016</span></span></span>

The practical lesson is not that willpower is imaginary or useless. It is that treating every lapse as evidence of weak character gives too much explanatory weight to the person at the exact moment of failure and too little to the system that repeatedly creates that moment.

## Why character explanations are incomplete

One reason the popular willpower story has been so influential is the **[ego-depletion]({{ 'ego-depletion/' | relative_url }})** hypothesis: the proposal that exerting self-control uses up a limited internal resource, leaving less available for the next challenge. An influential 2010 meta-analysis reported a substantial average depletion effect, helping establish the image of willpower as something rather like a muscle that becomes temporarily exhausted.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/20565167/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-title">Pub Med Ego depletion and the strength model of self-control: a meta-analysis</span><span class="citation-popover-snippet">Ego depletion and the strength model of self-control: a meta-analysis - PubMedJuly 1, 2010...</span><span class="citation-popover-meta">Published: July 1, 2010</span></span></span>

Later evidence made that simple account much harder to defend. Reanalyses found evidence consistent with publication and small-study biases, while a 2016 preregistered project involving 23 laboratories and 2,141 participants estimated an ego-depletion effect of only *d* = 0.04, with a confidence interval spanning zero. A subsequent preregistered 36-laboratory project involving 3,531 participants again found no significant effect in its confirmatory analysis, estimating *d* = 0.06. Another multilab replication, using a different protocol, did detect an effect, but it was small: *d* = 0.10 in the full sample and *d* = 0.16 after specified exclusions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/25126083/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Publication bias and the limited strength model of self-control: has the evidence for ego depletion been overestimated? - PubMedJul...</span></span></span>

The scientific dispute is not completely settled. A 2024 review by proponents of limited-willpower theories argues that improved methods, including stronger and longer fatigue manipulations, support the reality of depletion and that the original model should be refined rather than discarded. That makes “ego depletion has been disproved” an overstatement. But the evidence no longer justifies the stronger popular claim that ordinary self-control failures can generally be understood as a predictable emptying of a single willpower tank.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/article/pii/S2352250X24000952" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[ScienceDirect]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Open source on sciencedirect.com.</span></span></span>

Everyday data also resist an exclusively character-based interpretation. In an experience-sampling study, 205 adults supplied 7,827 reports about desires during a week. Whether people resisted successfully was associated not only with individual differences but with situational and interpersonal conditions. The presence and behaviour of other people, for example, were among the factors related to how desires developed and whether they were enacted.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/22149456/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

This suggests a better distinction. **Capacity matters, but exposure matters too.** Someone who checks social media five times during a working afternoon may indeed need to inhibit an urge at each encounter. But the behaviour is also being shaped by whether the phone is visible, [notifications]({{ 'notifications/' | relative_url }}) appear, the site is already open and checking requires almost no effort. Calling the fifth lapse “poor discipline” describes the end of the chain while ignoring most of the chain itself.

## How environments influence behaviour

The alternative to a character explanation is not environmental determinism. People still make choices. The important point is that choices do not arrive in a vacuum: their probability changes when the surrounding cues, costs and opportunities change.

A useful framework is the **process model of self-control**, which distinguishes strategies by how early they intervene. At the earliest point, a person can select or alter a situation; later, they can shift attention or reinterpret what is happening; only towards the end do they rely on direct inhibition of an already active impulse. Researchers argue that earlier interventions can be advantageous because they prevent a temptation from becoming as strong in the first place.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC4736542/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-title">Pub Med Central (PMC)Situational Strategies for Self-Control</span><span class="citation-popover-snippet">PubMed Central (PMC)Situational Strategies for Self-Control - PMCJanuary 1, 2016...</span><span class="citation-popover-meta">Published: January 1, 2016</span></span></span>

Daily-life research supports that anticipatory view. In two studies of strategic self-control, planning predicted whether people initiated self-control, while situation selection, situation modification, distraction and reappraisal each independently predicted goal progress. Direct response inhibition — the strategy closest to the everyday image of “using willpower” — did not show consistent associations with progress.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/31658876/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Nipping Temptation in the Bud: Examining Strategic Self-Control in Daily Life - PubMed...</span></span></span>

### Small amounts of friction can change what people do

“Friction” means the effort, inconvenience or number of steps required to perform an action. It can be physical — walking farther for something — or procedural, such as needing to log in again instead of opening an already authenticated app.

A workplace field study at Google provides a concrete illustration. Employees using a drinks station nearer the snack area were more likely to take food than those using a more distant station. Among men, the recorded likelihood rose from 12% to 23%; among women, from 13% to 17%. Nobody had been forbidden to eat, instructed to diet or given a test of discipline. A change of a few metres altered the behavioural context.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/27112315/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

Choice architecture research shows the same broad principle in other forms, although effects are neither universal nor permanent. A meta-analysis of 58 studies involving 73,675 participants found sizeable average effects from making one option the default, but also substantial variation between studies and a few cases where defaults had no effect or moved behaviour in the opposite direction. A systematic review of choice-architecture interventions targeting [physical activity]({{ 'physical-capacity/' | relative_url }}) likewise found that many interventions changed behaviour while they were in place, but evidence of persistence after their removal was weaker.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cambridge.org/core/journals/behavioural-public-policy/article/when-and-why-defaults-influence-decisions-a-metaanalysis-of-default-effects/67AF6972CFB52698A60B6BD94B70C2C0" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cambridge.org">[Cambridge University Press]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cambridge.org</span><span class="citation-popover-snippet">Open source on cambridge.org.</span></span></span>

That caveat is important. “Design your environment” should not become another self-help slogan promising effortless transformation. Environmental changes work differently across behaviours and people. A prompt may help someone take the stairs while it remains visible but cease to matter once removed. Defaults can be powerful in some decisions and weak in others. Systems alter probabilities; they do not abolish agency or guarantee outcomes.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cambridge.org/core/journals/behavioural-public-policy/article/when-and-why-defaults-influence-decisions-a-metaanalysis-of-default-effects/67AF6972CFB52698A60B6BD94B70C2C0" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cambridge.org">[Cambridge University Press]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cambridge.org</span><span class="citation-popover-snippet">Open source on cambridge.org.</span></span></span>

### Repetition can transfer some work from deliberation to cues

[Environment design]({{ 'design-around-temptation/' | relative_url }}) has another purpose beyond making tomorrow easier: it can help a useful response become habitual. In behavioural science, a habit is not merely something done frequently. It refers to a learned association through which a context or cue begins to prompt a response with increasing [automaticity]({{ 'automaticity/' | relative_url }}).<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC4566897/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

In a well-known real-world study, 96 volunteers chose an eating, drinking or activity behaviour and attempted to repeat it in a consistent context for 12 weeks. Automaticity generally increased with repetition, but at very different rates between individuals. Among participants for whom the researchers could model the process, estimates for reaching 95% of their eventual automaticity ranged from 18 to 254 days. Importantly, missing one opportunity did not materially derail the process.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Open source on wiley.com.</span></span></span>

A 2024 systematic review and meta-analysis reinforces the case against the popular “21-day habit” formula. Across the studies that reported formation times, medians were around 59–66 days and means around 106–154 days, with extremely wide individual variation. The review also cautioned that much of the underlying literature had a high risk of bias, so those figures are better treated as evidence of variability than as a new universal countdown.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC11641623/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

The point for willpower is straightforward: **repetition in a stable context can change the nature of the task**. At first, putting on walking shoes after lunch may require conscious remembering and negotiation. After enough consistent pairing, lunch itself may begin to cue the walk. Effort has not vanished from the universe; part of the initiation process has become more automatic.

This helps explain an otherwise counter-intuitive finding about people described as having high self-control. Across six studies involving 2,274 participants, beneficial habits partly accounted for the relationship between self-control and outcomes including healthy eating, [exercise]({{ 'exercise/' | relative_url }}), sleep, studying, homework completion and academic performance. Higher self-control was associated not simply with stronger inhibition but with routines that reduced the need for it.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/25643222/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">More than resisting temptation: Beneficial habits mediate the relationship between self-control and positive life outcomes - PubMed...</span></span></span>

## Replacing self-blame with system changes

A systems approach changes the diagnostic question after a lapse. Instead of immediately asking, “Why was I not disciplined enough?”, ask, **“What repeatedly made the unwanted action easier, earlier or more rewarding than the action I intended?”**

That shift is not an excuse to avoid responsibility. It makes responsibility more actionable. Character judgements such as “lazy” or “weak-willed” are difficult to modify directly. A phone beside the bed, an exercise plan requiring a 40-minute journey, or a study routine that begins only after opening a distracting browser can actually be changed.

For recurring failures, four types of system adjustment are especially useful:

* **Remove or weaken the cue to the unwanted behaviour.** Silence non-essential notifications, keep tempting purchases out of immediate view, or avoid repeatedly entering the situation in which the problem normally begins. Situation selection is itself a form of self-control, not a refusal to practise it.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC4736542/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-title">Pub Med Central (PMC)Situational Strategies for Self-Control</span><span class="citation-popover-snippet">PubMed Central (PMC)Situational Strategies for Self-Control - PMCJanuary 1, 2016...</span><span class="citation-popover-meta">Published: January 1, 2016</span></span></span>
* **Add friction to the behaviour you want less of.** Logging out of an app, moving distracting devices to another room or not storing an impulse-purchase payment method cannot make a behaviour impossible, but each creates a moment in which the automatic sequence can be interrupted. Research on proximity and choice architecture illustrates why seemingly trivial effort costs can matter.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/27112315/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>
* **Remove friction from the behaviour you want more of.** Put the needed equipment where the behaviour starts, prepare the workspace before it is needed, or make the healthier/default option the one requiring fewer steps. The objective is to stop demanding a fresh motivational victory at every repetition.
* **Give the desired action a stable cue.** “I will read more” leaves initiation to memory and mood. “After I put my evening drink down, I read five pages in the chair beside the window” provides a recurring context in which an association can develop. Consistent context and repetition are central to established accounts of habit formation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Open source on wiley.com.</span></span></span>

The same reasoning changes how setbacks should be interpreted. One missed workout in an otherwise stable routine need not be treated as evidence that the habit has collapsed; Lally and colleagues found that a single missed opportunity did not materially alter the habit-formation trajectory. Repeated misses in the *same circumstances*, however, are useful information. If a planned evening run fails every time work finishes late, the persistent variable may be the timing and context rather than insufficient moral resolve.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Open source on wiley.com.</span></span></span>

Systems also need to fit the problem. A 2024 review of everyday self-control strategies stresses that there is no single strategy that works best across all people and situations. Sometimes avoiding temptation is practical; sometimes it is impossible. Some behaviours can be automated readily, whereas complex actions continue to require planning, attention and inhibition. The strongest systems therefore reduce unnecessary self-control demands rather than pretending those demands can be eliminated altogether.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/39241278/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

## The useful version of discipline

The most defensible conclusion is not “willpower does not matter”. It is that **willpower is a poor place to put every behavioural burden**.

Effortful self-control can still be necessary: to begin changing an environment, interrupt an established habit, recover when circumstances change or act when no convenient system is available. Research on ego depletion remains contested rather than settled, and individual differences in self-control continue to predict meaningful outcomes. But successful self-regulation appears to include more than repeatedly suppressing impulses after they have become strong.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/article/pii/S2352250X24000952" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[ScienceDirect]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Open source on sciencedirect.com.</span></span></span>

A more useful conception of discipline is therefore partly architectural. It includes deciding which situations to enter, which temptations not to keep within reach, which useful actions deserve the easiest path, and which cues should reliably prompt the next step. Over time, repetition can make some of those choices less deliberative and less effortful.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/26817725/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[nih.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-title">Pub Med Situational Strategies for Self-Control</span><span class="citation-popover-snippet">Pub Med Situational Strategies for Self-Control</span></span></span>

That perspective also changes the emotional meaning of inconsistency. A lapse can still require correction, but it need not become a referendum on character. When the same failure keeps occurring under the same conditions, the repeated pattern is evidence about the conditions. Good self-improvement uses that evidence: alter the cue, change the friction, redesign the sequence and make the next desirable action easier to repeat.

      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
