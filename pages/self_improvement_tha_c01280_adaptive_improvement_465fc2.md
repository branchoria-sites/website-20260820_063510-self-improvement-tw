## Introduction

Adaptive self-improvement means treating a repeatedly failing routine as a design problem rather than repeatedly demanding more effort from the same design. Monitoring is useful because it reveals a gap between intention and behaviour; the important next step is to use that information to change the conditions producing the behaviour. Research on self-regulation describes this as a [feedback]({{ 'feedback/' | relative_url }}) process: compare what happened with what was intended, decide whether the present strategy still fits, and alter the strategy when progress remains inadequate.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/4975085/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">PubMed Central (PMC)Theoretical explanations for maintenance of behaviour change: a systematic review of behaviour theories - PMCJuly 2...</span></span></span>

This approach is deliberately different from changing everything after one bad day. Single lapses are noisy: illness, travel, an unusual deadline or simple chance can disrupt a sound routine. Repeated failures in a similar situation are more informative. They suggest that the plan may contain a predictable point of friction — the timing, cue, workload, environment, response to obstacles or even the target itself. The practical aim is therefore to identify that recurring failure window, make the smallest plausible adjustment, and [re-test]({{ 're-test/' | relative_url }}) the redesigned routine before escalating to a larger change.

## Recognise a pattern before redesigning the plan

A useful self-improvement system distinguishes an **event** from a **pattern**. Missing one planned evening run after an exceptionally long workday tells you little. Missing most evening runs specifically on days when work finishes late tells you much more: the routine appears vulnerable during a recognisable time window.

Progress monitoring helps expose patterns of this kind. A meta-analysis of 138 experimental studies involving 19,951 participants found that interventions designed to increase progress monitoring increased both monitoring frequency and goal attainment; changes in monitoring frequency statistically mediated the improvement in attainment. Effects were larger when progress was physically recorded or reported to someone else.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/26479070/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Does monitoring goal progress promote goal attainment? A meta-analysis of the experimental evidence - PubMedFebruary 1, 2016...</span><span class="citation-popover-meta">Published: February 1, 2016</span></span></span> That supports tracking, but it does not mean that merely collecting more data solves the problem. A wider meta-review found that self-monitoring, feedback and goal-setting techniques work inconsistently across behaviours and populations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC7571594/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">PubMed Central (PMC)Self-Regulation Mechanisms in Health Behaviour Change: A Systematic Meta-Review of Meta-Analyses, 2006–2017 - PMCMarc...</span></span></span>

* **Starting failure:** the intended action never begins — for example, study sessions disappear whenever they are scheduled after dinner.
* **Completion failure:** the action starts but its planned size is repeatedly unrealistic — a 60-minute workout becomes ten minutes or nothing.
* **Cue failure:** the intended trigger is unreliable — “when I get some free time” never creates a dependable starting point.
* **Obstacle failure:** the same foreseeable interruption repeatedly defeats the plan — late meetings, childcare, tiredness, missing equipment or distracting devices.
* **Recovery failure:** one missed attempt turns into several because the system contains no clear rule for restarting.

</div>

This classification matters because the appropriate adjustment depends on where the failure occurs. Moving the workout earlier will not solve an [exercise]({{ 'exercise/' | relative_url }}) routine whose real problem is that it requires equipment the person rarely has available. Reducing session length will not fix a cue that never occurs consistently.

Behaviour-change guidance reflects this distinction between tracking and revision. NICE describes [behaviour goals]({{ 'behaviour-goals/' | relative_url }}) as things that should be reviewed in light of experience, with further plans made according to previous progress; its framework places monitoring alongside action planning rather than treating either as sufficient alone.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nice.org.uk/Guidance/PH49/chapter/recommendations" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nice.org.uk">[Nice]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nice.org.uk</span><span class="citation-popover-snippet">Recommendations &#124; Behaviour change: individual approaches &#124; Guidance &#124; NICEJanuary 2, 2014...</span><span class="citation-popover-meta">Published: January 2, 2014</span></span></span>

Repeated failure should also be interpreted locally before it is interpreted globally. Older relapse research provides an especially clear example: treating a lapse as proof of personal incapacity can increase the risk that the lapse becomes a broader relapse, whereas attributing it to an ineffective response to a specific high-risk situation creates an opportunity to develop a better response for the next occurrence.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC6760427/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span> Although those findings come from addiction research and should not simply be generalised to every self-improvement goal, the governance lesson is useful: diagnose the failed interaction between person, plan and situation before concluding that the entire goal or the person pursuing it is defective.

## Make the smallest adjustment that could fix the failure

Once a recurring pattern is visible, the temptation is to redesign everything: a new app, a stricter schedule, a different diet, a larger goal or a more complicated productivity system. That makes the next result difficult to interpret. If five things change simultaneously and performance improves, you do not know which change mattered; if performance worsens, you do not know what caused that either.

A better rule is **minimum useful adjustment**: change the smallest element that plausibly targets the repeated failure.

Suppose the intended routine is “write for 45 minutes at 19:00”, but tracking shows that it fails four evenings out of five because family responsibilities make that window unpredictable. Possible interventions range from tiny to radical. The first test might simply move the session to 07:30. If starting remains difficult, the next adjustment might prepare the document and notes the previous night. Only after smaller changes fail would it make sense to question the session length, frequency or larger goal.

This mirrors a central idea in contemporary models of self-regulation. Monitoring does not merely indicate whether a goal has been reached; it can signal whether the current strategy or tactic should be maintained, changed or stopped. When a selected tactic produces insufficient progress, the person can return to strategy selection and try a different response rather than simply repeating the ineffective one.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://compass.onlinelibrary.wiley.com/doi/10.1111/spc3.12738" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: compass.onlinelibrary.wiley.com">[Compass]</a><span class="citation-popover" role="note"><span class="citation-popover-source">compass.onlinelibrary.wiley.com</span><span class="citation-popover-title">Compass Self‐control: An integrative framework</span><span class="citation-popover-snippet">Self‐control: An integrative framework - Werner - 2023 - Social and Personality Psychology Compass - Wiley Online Library...</span></span></span>

The most useful adjustment usually targets the mechanism exposed by the record:

**If the problem is timing, change the window.** A planned behaviour that repeatedly collides with predictable demands should be moved rather than protected indefinitely through willpower. “Exercise after work” might become “exercise before the first meeting” or “walk during lunch”.

**If the problem is scale, lower the entry requirement.** A routine can be sound in principle yet too large to survive ordinary low-energy days. The redesign may preserve the frequency while shortening the minimum session.

**If the problem is an obstacle, plan the response to that obstacle.** Behaviour-change research distinguishes action planning — specifying when, where and how a behaviour will occur — from coping planning, which specifies what to do when anticipated barriers arise. A systematic review found variable but generally supportive evidence for coping planning, particularly where people received help forming their plans, while a broader review of planning interventions found small-to-medium effects across health behaviours but considerable heterogeneity.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.tandfonline.com/doi/abs/10.1080/17437199.2013.766832" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tandfonline.com">[Taylor &amp; Francis Online]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tandfonline.com</span><span class="citation-popover-snippet">Open source on tandfonline.com.</span></span></span> In practice, “I will walk at lunch” becomes “I will walk at lunch; if rain makes the normal route impractical, I will use the covered route through the shopping centre.”

**If the environment repeatedly wins, change the environment.** Removing friction from the intended behaviour or adding friction to the competing behaviour is often more targeted than strengthening the intention yet again. If every planned reading session becomes phone use, testing a phone-free room is a cleaner intervention than writing a more inspirational reading goal.

**If the plan works only under ideal conditions, create a [fallback mode]({{ 'fallback-mode/' | relative_url }}).** A resilient system may contain an ordinary version and a reduced version: 40 minutes of training normally, 10 minutes when time collapses; cooking the planned meal normally, a pre-selected simple alternative when work runs late. The fallback should preserve continuity without quietly becoming an excuse to abandon the intended standard altogether.

The governing principle is diagnosis before escalation. Behaviour-change taxonomies contain many possible techniques — UCL's Behaviour Change Technique Taxonomy identifies 93 — but government guidance explicitly cautions that researchers still do not know with certainty which combinations work best for every behaviour, person and moment.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ucl.ac.uk/brain-sciences/behaviour-change/resources/advancing-behavioural-science" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ucl.ac.uk">[University College London]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ucl.ac.uk</span><span class="citation-popover-snippet">Open source on ucl.ac.uk.</span></span></span> Adding more techniques is therefore not automatically an improvement. A change earns its place because it addresses an observed failure mode.

## Re-test the redesigned routine

An adjustment is a hypothesis, not a solution merely because it sounds sensible. The redesigned routine has to be exposed to the situation that previously defeated it.

This is where an **event-time-window** view becomes especially useful. Instead of asking whether the plan works “in general”, watch the specific window associated with failure. If the original problem was skipped workouts after late meetings, evaluate the replacement routine across several late-meeting days. If impulse spending was concentrated on Sunday evenings, test the new purchasing rule across several Sunday evenings. The relevant unit is not the calendar week in the abstract but repeated encounters with the condition you are trying to govern.

A practical review cycle has three decisions:


<div class="content-enhancement content-enhancement--step-flow" markdown="1">

1. **Keep it** when the redesigned routine now succeeds reliably enough in the previously troublesome situation.
2. **Modify it again** when the same failure mechanism remains visible.
3. **Diagnose a different problem** when the original failure disappears but another bottleneck emerges.

</div>

That final possibility is important. Behavioural systems can move their constraint. Moving exercise to the morning may solve scheduling but expose a preparation problem because clothing and equipment are never ready. Preparing everything the night before may then reveal that the planned session itself is too long. Adaptive improvement is consequently iterative: each test generates information for the next decision.

Repeated prompting may sometimes be part of that redesign rather than a permanent requirement. One study of implementation-intention prompts among medical students found that performance benefits built across consecutive days of prompting but faded after prompting stopped, illustrating that an intervention can work while it is present without automatically creating a durable self-sustaining routine.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/article/pii/S0959475221001195" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[ScienceDirect]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Open source on sciencedirect.com.</span></span></span> That distinction matters when evaluating any redesign. Ask not only whether performance improved immediately, but whether the new arrangement remains workable once temporary supports are reduced.

Re-testing also protects against a common mistake: abandoning a useful system because of normal variance. No realistic routine produces perfect adherence. The question is whether the adjustment has meaningfully changed the *pattern*. If a person previously missed four of five vulnerable occasions and now misses one of five, the redesign is doing useful work even though the record is not flawless.

## Know when to adjust the system — and when to adjust the goal

Most repeated failures should initially trigger a change in **how** the goal is pursued, not an immediate abandonment of **what** the person values. But persistence is not always the right answer. Sometimes repeated difficulty indicates that the target itself has become unrealistic, excessively costly or incompatible with changed circumstances.

A 2025 meta-analytic review synthesising 235 studies and 1,421 effect sizes distinguishes several forms of goal adjustment, including disengaging from a goal, re-engaging with alternatives and remaining flexible about how striving occurs. The authors emphasise that adjustment is not a single uniformly beneficial act and rate the accumulated evidence as only low to moderate overall because much of it is cross-sectional and heterogeneous.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC12932095/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span> That caution is important: “be flexible” is not an evidence-based licence to quit whenever progress is uncomfortable.

Still, the evidence challenges the opposite rule that perseverance is invariably virtuous. An earlier meta-analysis across 31 samples found that capacities for both goal disengagement and re-engagement were positively associated with quality of life, with the association larger for re-engagement than disengagement.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/31131441/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-title">Pub Med Goal adjustment capacities and quality of life: A meta-analytic review</span><span class="citation-popover-snippet">Pub Med Goal adjustment capacities and quality of life: A meta-analytic review</span></span></span> The reasonable interpretation is not that difficult goals should be abandoned, but that a mature self-improvement system needs an escalation path.

The sequence should ordinarily be:

**First, question the tactic.** Can the timing, cue, environment, scale or obstacle response be redesigned?

**Then, question the strategy.** Is there another route to the same valued outcome? Someone unable to sustain running because of recurring practical or physical constraints may still pursue cardiovascular fitness through walking, cycling or swimming.

**Only then, when evidence warrants it, question the goal specification.** Is the target still attainable, valuable and proportionate to its costs?

This hierarchy prevents two symmetrical errors: treating every setback as proof that the goal should be abandoned, and treating years of repeated failure as proof that still more determination is required.

## Build a rule for adaptation before the next failure

The strongest version of this approach makes adjustment part of the original system rather than an emergency response improvised during discouragement. In effect, the plan contains a small governance rule: **when a particular failure repeats often enough, review the mechanism and change one thing.**

The threshold does not need to be mathematically sophisticated. For a behaviour attempted daily, three or four failures under similar circumstances may justify inspection. For a weekly behaviour, it may be sensible to review after several opportunities rather than waiting months. The appropriate window depends on the frequency and stakes of the behaviour, but the threshold should be large enough to distinguish a pattern from an isolated exception and small enough to prevent an obviously faulty design from running indefinitely.

A useful review can be reduced to four questions:


<div class="content-enhancement content-enhancement--step-flow" markdown="1">

1. **What exactly keeps failing?** Name the behaviour, not the character judgement.
2. **When does it keep failing?** Identify the recurring situation or time window.
3. **What is the smallest plausible cause?** Look first at timing, friction, scale, cues and foreseeable barriers.
4. **What single change will be tested next?** Define the adjustment clearly enough that its effect can be observed.

</div>

This closes the loop that makes monitoring worthwhile. Self-improvement becomes less like issuing the same instruction to yourself with increasing frustration and more like maintaining a working system: observe performance, locate the recurring fault, make a controlled adjustment, and test again.

That approach is also consistent with the limits of the evidence. Reviews of self-regulatory interventions repeatedly find useful average effects for techniques such as monitoring, planning and feedback, but they also find substantial variation across behaviours, populations and contexts.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC7571594/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">PubMed Central (PMC)Self-Regulation Mechanisms in Health Behaviour Change: A Systematic Meta-Review of Meta-Analyses, 2006–2017 - PMCMarc...</span></span></span> The practical lesson is not to search for a universally correct routine. It is to build a routine capable of learning from its own repeated failures.

## The practical standard: improve the system, not the story about yourself

Repeated failure contains information only if it is made specific. “I am undisciplined” offers almost no design guidance. “My planned study block fails whenever it starts after 20:00 because I switch to passive entertainment first” points towards testable interventions: move the session, shorten it, change the preceding cue or restrict access to the competing activity during that window.

That difference is the heart of adaptive self-improvement. A sound plan is not sacred. It is provisional. Monitoring identifies recurring discrepancies; diagnosis turns them into plausible mechanisms; [small adjustments]({{ 'small-adjustments/' | relative_url }}) test those mechanisms; re-testing shows whether the system has actually improved. Control-theory accounts of self-regulation have long described behaviour in these feedback-loop terms, and modern work on self-regulatory flexibility likewise emphasises matching strategies to changing situations rather than assuming that one strategy should always work.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cambridge.org/core/books/abs/handbook-of-behavior-change/changing-behavior-using-control-theory/6F7BD075E7046390F126A4F445A7B02A" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cambridge.org">[Cambridge University Press]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cambridge.org</span><span class="citation-popover-title">University Press Changing Behavior Using Control Theory (Chapter 9</span><span class="citation-popover-snippet">University Press Changing Behavior Using Control Theory (Chapter 9</span></span></span>

The standard of success is therefore not never failing. It is becoming progressively better at responding to failure. When the same breakdown keeps appearing, do not merely renew the promise. Change the part of the system that keeps producing it.

    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
