## Introduction

There is no scientifically established number of days after which a new behaviour suddenly becomes a habit. The familiar **21-day rule** is not a finding from modern habit research, and even the better-known figure of **66 days** should not be treated as a replacement deadline. Studies instead show a wide spread: some relatively simple behaviours become substantially automatic within weeks, while others take many months, and some people do not reach the researchers’ chosen habit threshold during the study at all.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Wiley Online LibraryHow are habits formed: Modelling habit formation in the real world - Lally - 2010 - European Journal of Social Psycho...</span></span></span>

The most useful lesson for self-improvement is therefore not “repeat this for exactly X days”. It is to expect a **gradual learning process whose speed depends on the person, the behaviour and the circumstances in which it is repeated**. A 2024 systematic review of health-related habits found median [formation times]({{ 'formation-times/' | relative_url }}) of roughly two months in the studies that directly measured them, but individual estimates stretched from **4 to 335 days**. Just as importantly, the review found that surprisingly few studies have actually measured how long habit formation takes.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC11641623/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

## Why 21 days is not a rule

The 21-day claim can be traced largely to plastic surgeon Maxwell Maltz and his 1960 book *Psycho-Cybernetics*. Maltz described observations such as patients adjusting to changes in their appearance and argued that it generally took a **minimum of about 21 days** for a changed mental image to become familiar. The passage was about adjustment and self-image rather than a controlled experiment testing how long everyday behaviours take to become habitual.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.penguinrandomhouse.ca/books/318795/psycho-cybernetics-by-maxwell-maltz-md-fics/9780399176135/excerpt" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: penguinrandomhouse.ca">[Penguin Random House Canada]</a><span class="citation-popover" role="note"><span class="citation-popover-source">penguinrandomhouse.ca</span><span class="citation-popover-snippet">Open source on penguinrandomhouse.ca.</span></span></span>

That distinction became blurred as the idea travelled through self-help culture. “A minimum of about 21 days” is easily transformed into the much simpler promise that doing something for 21 consecutive days creates a habit. But the two statements are not equivalent. Maltz was not establishing a universal behavioural threshold, and contemporary habit research does not support one.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.penguinrandomhouse.ca/books/318795/psycho-cybernetics-by-maxwell-maltz-md-fics/9780399176135/excerpt" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: penguinrandomhouse.ca">[Penguin Random House Canada]</a><span class="citation-popover" role="note"><span class="citation-popover-source">penguinrandomhouse.ca</span><span class="citation-popover-snippet">Open source on penguinrandomhouse.ca.</span></span></span>

The deeper problem is the assumption that habit formation resembles crossing a finish line. In behavioural science, a habit is usually understood not merely as something done frequently but as a response that becomes increasingly **automatically prompted by a recurring context or cue**. Repeating an action in a sufficiently stable situation gradually strengthens the association between that situation and the response.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.tandfonline.com/doi/full/10.1080/17437199.2011.603640" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tandfonline.com">[Taylor &amp; Francis Online]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tandfonline.com</span><span class="citation-popover-snippet">Taylor &amp; Francis OnlinePromoting habit formation: Health Psychology Review: Vol 7, No sup1 - Get AccessOctober 11, 2011...</span><span class="citation-popover-meta">Published: October 11, 2011</span></span></span>

That learning process does not ordinarily jump from “not a habit” on day 20 to “habit” on day 21. In the influential real-world study by Phillippa Lally and colleagues, participants’ increases in [automaticity]({{ 'automaticity/' | relative_url }}) were better represented by an **asymptotic curve**: gains tended to be larger earlier and then became progressively smaller as automaticity approached a plateau.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Wiley Online LibraryHow are habits formed: Modelling habit formation in the real world - Lally - 2010 - European Journal of Social Psycho...</span></span></span>

This makes fixed challenges easy to misunderstand. Completing 21 days of walking, reading or stretching can certainly establish useful repetition. It simply does not mean that the behaviour is now permanently automatic, nor that needing deliberate effort on day 22 represents failure.

## What modern research actually estimates

The study responsible for the famous “66 days” figure followed 96 volunteers who selected a new eating, drinking or [physical-activity]({{ 'physical-capacity/' | relative_url }}) behaviour and tried to perform it daily in the same context for 12 weeks. They repeatedly rated how automatic the behaviour felt. Among participants whose data could be modelled appropriately, estimated time to reach 95% of their eventual automaticity varied from **18 to 254 days**. Later summaries report a median of about **66 days**.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Wiley Online LibraryHow are habits formed: Modelling habit formation in the real world - Lally - 2010 - European Journal of Social Psycho...</span></span></span>

The range matters more than the headline number. Sixty-six days was a description of the middle of a highly variable distribution in a particular study, not a biological rule. Moreover, the mathematical habit-formation curve fitted only 62 participants’ data, and fitted particularly well for 39, another reason not to turn the estimate into a universal countdown.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Wiley Online LibraryHow are habits formed: Modelling habit formation in the real world - Lally - 2010 - European Journal of Social Psycho...</span></span></span>

Subsequent studies have produced similarly varied estimates. A 2024 systematic review and meta-analysis examined 20 studies involving 2,601 participants and health-related behaviours including physical activity, healthier eating, water consumption, flossing and reduced sedentary behaviour. Only **four studies**, however, directly reported a mean or median time to habit formation. Across those studies, medians were **59 to 66 days**, while means ranged from **106 to 154 days**. Individual estimates across relevant studies ranged from **4 to 335 days**.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC11641623/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

Some examples show why one average conceals so much:

* In one healthy-eating study, those who reached the specified habit threshold did so in a median of **59 days**, but estimates ranged from **4 to 335 days**, and only about **23% of participants** reached that threshold.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC11641623/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>
* Lally and colleagues’ eating, drinking and activity study produced the frequently cited **66-day** estimate, with individual modelled times ranging from **18 to 254 days**.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Wiley Online LibraryHow are habits formed: Modelling habit formation in the real world - Lally - 2010 - European Journal of Social Psycho...</span></span></span>
* In a 90-day study of a daily stretching routine, researchers extrapolated the learning curves to estimate automaticity at roughly **106 days for morning stretching and 154 days for evening stretching**.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/28650196/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-title">Pub Med Effects of circadian cortisol on the development of a health habit</span><span class="citation-popover-snippet">Effects of circadian cortisol on the development of a health habit - PubMedNovember 1, 2017...</span><span class="citation-popover-meta">Published: November 1, 2017</span></span></span>
* Another study in the review, using participants’ own reports for healthy eating and self-weighing, produced a mean estimate of about **91 days**, with substantial variation around that average.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC11641623/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

The 2024 review therefore concluded that health habits may commonly require roughly **two to five months** to develop substantial automaticity, while stressing the considerable person-to-person variation. That is a more defensible expectation than three weeks, but it still should not be interpreted as a guaranteed window.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC11641623/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

There is another reason for caution: the evidence base remains thinner than the confidence of popular habit advice might suggest. Of the 20 studies in that review, only four directly yielded formation-time estimates, and 11 were rated as having a high risk of bias. The authors explicitly identified the scarcity of studies directly measuring time to habit formation as an important research gap.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC11641623/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

So “science says it takes 66 days” is only marginally better than “science says 21 days”. The more accurate summary is that **habit formation is gradual, measurable timelines vary enormously, and current research does not justify a single countdown for everyone or every behaviour**.

## Why individual timelines vary so much

Variation is not statistical noise that can simply be averaged away. It reflects meaningful differences in what people are trying to automate and the circumstances in which they repeat it.

One important factor is **behavioural complexity**. Drinking a glass of water after breakfast is a short, discrete response with a clear cue. “[Exercise]({{ 'exercise/' | relative_url }}) regularly” may involve changing clothes, travelling somewhere, choosing a workout and sustaining substantial effort. The 2024 review found that the type of behaviour was among the factors associated with habit development, and the wide estimates across eating, stretching, activity and other behaviours make clear that they cannot sensibly be assumed to share an identical timetable.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC11641623/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

A second factor is **repetition in a stable context**. Habit theory proposes that repeated behaviour becomes linked to situational cues. The cue might be finishing breakfast, arriving home, entering a particular room or completing another routine. Research examining context stability has found that more stable contexts are associated with greater automaticity and better goal attainment, supporting the idea that simply counting repetitions without considering where and when they occur misses part of the learning process.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC9226889/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

This helps explain why “I have done it 30 times” is not necessarily equivalent to “I have trained the same cue-response relationship 30 times”. Thirty repetitions scattered unpredictably across different situations may produce a different learning history from 30 repetitions consistently attached to the same recurring event.

Timing can matter too, although findings should not be overgeneralised from individual studies. In the stretching experiment, the morning group’s habit curve developed faster than the evening group’s, with researchers proposing a role for normal daily variation in cortisol. The 2024 review likewise identified timing among the factors associated with habit strength.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/28650196/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-title">Pub Med Effects of circadian cortisol on the development of a health habit</span><span class="citation-popover-snippet">Effects of circadian cortisol on the development of a health habit - PubMedNovember 1, 2017...</span><span class="citation-popover-meta">Published: November 1, 2017</span></span></span>

Personal choice, enjoyment, behavioural regulation and frequency of performance also emerged as potentially relevant determinants in the review. These findings are useful partly because they undermine the notion of a standard human habit clock: two people performing nominally the same behaviour may experience different rewards, barriers, schedules and [environmental cues]({{ 'useful-cues/' | relative_url }}).<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC11641623/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

## A missed day does not reset the clock

The deadline myth often comes with a second misconception: that uninterrupted streaks are essential and a single lapse sends progress back to zero.

Lally and colleagues found that **missing one opportunity to perform the behaviour did not materially disrupt the habit-formation process**. Automaticity accumulated through repeated experience rather than behaving like a streak counter that reset after a lapse.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Wiley Online LibraryHow are habits formed: Modelling habit formation in the real world - Lally - 2010 - European Journal of Social Psycho...</span></span></span>

That does not mean [consistency]({{ 'consistency/' | relative_url }}) is irrelevant. More consistent performance was associated with better-fitting habit-development curves, and repetition remains fundamental to the proposed learning mechanism. The important distinction is between **occasional misses and persistent inconsistency**. One missed walk or forgotten vitamin is not evidence that all previous learning has vanished; repeatedly failing to enact the behaviour in its intended context is a more consequential problem.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Wiley Online LibraryHow are habits formed: Modelling habit formation in the real world - Lally - 2010 - European Journal of Social Psycho...</span></span></span>

This is one of the most practically useful consequences of abandoning the 21-day model. A rigid deadline encourages binary thinking: either the streak survives or it has been “broken”. The research points instead towards accumulated learning. What matters is whether the cue-response association keeps receiving enough repeated reinforcement over time.

## The better question is not “What day will it become automatic?”

Habit studies often need a numerical threshold so researchers can analyse data, but everyday life does not provide a single objective moment when an action officially qualifies as a habit. In research, automaticity is commonly measured with questionnaires and modelled as a continuous variable that rises with repetition. Reviews of the field also caution that habit measurement has relied heavily on self-report and that researchers have not always used the term “habit” consistently.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC4566897/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">PubMed Central (PMC)A review and analysis of the use of ‘habit’ in understanding, predicting and influencing health-related behaviour - PMC...</span></span></span>

For self-improvement, it is therefore more useful to watch for **changing effort** than to await a particular date. A behaviour is moving in a habitual direction when the familiar situation increasingly prompts the action with less conscious negotiation: finishing breakfast starts to cue taking medication, shutting a laptop starts to cue laying out tomorrow’s work, or arriving home starts to cue a short walk.

The shape of Lally and colleagues’ results also suggests that early repetition deserves patience. Because automaticity tended to rise towards a plateau rather than appearing all at once, a behaviour can be meaningfully strengthening even while it still feels deliberate.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Wiley Online LibraryHow are habits formed: Modelling habit formation in the real world - Lally - 2010 - European Journal of Social Psycho...</span></span></span>

A more evidence-aligned expectation is therefore:

**Think in months rather than in a three-week promise, but do not turn “two months” or “66 days” into a new myth.** Simple behaviours may automate faster; demanding ones may take much longer; some people will progress unusually quickly or slowly; and not every attempt reaches high automaticity at all. The current evidence supports a range, not a deadline.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC11641623/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

## What realistic timelines change

Replacing the 21-day promise with a variable timeline changes the interpretation of early difficulty. If a new behaviour still requires reminders after three or four weeks, that is not evidence that habit formation has failed. In the best-known longitudinal study, many modelled trajectories extended far beyond that point, and the recent systematic review places typical health-habit estimates substantially later.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: onlinelibrary.wiley.com">[Wiley Online Library]</a><span class="citation-popover" role="note"><span class="citation-popover-source">onlinelibrary.wiley.com</span><span class="citation-popover-snippet">Wiley Online LibraryHow are habits formed: Modelling habit formation in the real world - Lally - 2010 - European Journal of Social Psycho...</span></span></span>

It also changes what a useful commitment period looks like. A “21-day challenge” can be a convenient starting structure, but its end should not be confused with the end of habit formation. For behaviours that matter, continuing repetition for several months is more consistent with the empirical literature than assuming three weeks will make the behaviour effortless.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC11641623/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

Most importantly, the research redirects attention from **counting days** to **building repeatable conditions**. Habit formation is better understood as repeated learning in context than as serving a fixed sentence of willpower. The calendar still matters because learning requires time, but the evidence does not support a magic day on which discipline can safely be switched off.

For [self-improvement that works]({{ 'self-improvement-that-works/' | relative_url }}), the useful milestone is therefore not day 21, day 66 or any other universal number. It is the point at which a well-chosen cue increasingly brings the desired behaviour to mind and makes starting it easier — a process that research suggests may take weeks for some behaviours, several months for many others, and substantially longer in some people.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.tandfonline.com/doi/full/10.1080/17437199.2011.603640" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: tandfonline.com">[Taylor &amp; Francis Online]</a><span class="citation-popover" role="note"><span class="citation-popover-source">tandfonline.com</span><span class="citation-popover-snippet">Taylor &amp; Francis OnlinePromoting habit formation: Health Psychology Review: Vol 7, No sup1 - Get AccessOctober 11, 2011...</span><span class="citation-popover-meta">Published: October 11, 2011</span></span></span>

    for (var i = 0; i< languages.length; i += 1) {
      var normalized = normalize(languages[i]);
      if (!normalized) continue;
      if (localeMarketMap[normalized]) {
        exactMarket = localeMarketMap[normalized];
        break;
      }
      var languageOnly = normalized.split('-')[0];
      if (!languageMarket && localeMarketMap[languageOnly]) languageMarket = localeMarketMap[languageOnly];
    }
    return { exact: exactMarket, language: languageMarket };
  }
  function inferFromLocale() {
    var matches = localeMatches();
    return matches.exact || matches.language || '';
  }
  function inferFromTimezone() {
    var tz = '';
    try { tz = String(Intl.DateTimeFormat().resolvedOptions().timeZone || ''); } catch (err) {}
    if (!tz) return '';
    for (var i = 0; i< timezoneRules.length; i += 1) {
      var rule = timezoneRules[i] || {};
      try {
        if (new RegExp(rule.pattern).test(tz)) return rule.market;
      } catch (err) {}
    }
    return '';
  }
  function inferMarket(available, options) {
    available = Array.isArray(available) ? available : [];
    options = options || {};
    var storageKey = options.storageKey || 'phoenix-affiliate-market';
    try {
      var saved = window.localStorage && localStorage.getItem(storageKey);
      if (saved && available.indexOf(saved) >= 0) return saved;
    } catch (err) {}
    var timezoneMarket = inferFromTimezone();
    if (timezoneMarket && available.indexOf(timezoneMarket) >= 0) return timezoneMarket;
    var localeMarkets = localeMatches();
    if (localeMarkets.exact && available.indexOf(localeMarkets.exact) >= 0) return localeMarkets.exact;
    if (localeMarkets.language && available.indexOf(localeMarkets.language) >= 0) return localeMarkets.language;
    if (options.defaultMarket && available.indexOf(options.defaultMarket) >= 0) return options.defaultMarket;
    return available[0] || '';
  }
  window.PhoenixAffiliateLocation = {
    normalize: normalize,
    inferMarket: inferMarket,
    inferFromLocale: inferFromLocale,
    inferFromTimezone: inferFromTimezone
  };
